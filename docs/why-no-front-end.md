# Why no front end

The work is a sequence of evidence checks: read an invoice, match its supplier and order, check receipts, resolve exceptions and record a second-person review. A coding agent can run those steps against the database. Read-only HTML gives finance the review pack and the week's queue.

A screen offers side-by-side image validation, click-to-correct fields, mobile capture and live collaboration. This base does not ship those features, an OCR model, a document archive or an unattended mailbox. /capture-invoice is a supervised workflow using the agent's document-reading tools. Enterprise DNA can build and connect the capture workflow and screens a business needs.

Documents, views and drafts are static snapshots, not live screens. Regenerate them after changes. No server, web application or write controls ship here.
